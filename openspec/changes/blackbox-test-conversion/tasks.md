## Execution model

Each work unit below is a closed contract, dispatched to one worker and verified
by the orchestrator running the code — never by reading the worker's report.
A unit is complete only when `./tests/run.sh` has been run and a real exit code
read from a redirected file.

Every unit is governed by `specs/black-box-harness/spec.md`. A unit that
violates a requirement there is rejected regardless of whether the suite passes.

## Rejected work — recorded so it is not silently redone

A parallel orchestrator converted 12 `lib/*.sh` callers between 23:26 and 23:58
on 2026-08-18. The conversions were correct in FORM but lost **50 net assertions**
(138 removed, 88 added), including 12 failure-path assertions. One confirmed
intent inversion in `test_upgrade.py::test_missing_ai_specs_home`:

```diff
-    self.assertNotEqual(result.returncode, 0)
-    self.assertIn("install.sh", result.stderr)
+    self.assertEqual(result.returncode, 0, result.stderr)
+    self.assertIn("up to date", result.stdout.lower())
```

A test whose entire purpose is the missing-`AI_SPECS_HOME` path was rewritten to
assert success. It passes and covers nothing. That work was reverted; its two
sound artifacts (`_cache_paths.py` decoupling, the cache-key parity assertion)
were kept.

This is the failure mode the whole card exists to prevent, so unit 7 carries an
explicit assertion-count gate: a converted file MUST NOT reduce its assertion
count without a per-assertion written justification.
